2.10 Recycling Rule of Vectors

c(1, 2, 3, 4) + c(1, 2)
[1] 2 4 4 6
# c(1, 2, 3, 4) + c(1, 2, 1, 2)

\[ \begin{bmatrix} 1 \\ 2 \\ 3 \\ 4 \end{bmatrix} + \begin{bmatrix} 1 \\ 2 \end{bmatrix} \xrightarrow{recyle} \begin{bmatrix} 1 \\ 2 \\ 3 \\ 4 \end{bmatrix} + \begin{bmatrix} 1 \\ 2 \\ 1 \\ 2 \end{bmatrix} \xrightarrow{add} \begin{bmatrix} 2 \\ 4 \\ 4 \\ 6 \end{bmatrix} \]

3 statistical Tables

  • d -> probability densities function
  • p -> cumulative probability function
  • q -> inverse cumulative distribution function
  1. norm Normal Distribution
  2. chisq Chi-squared Distribution
  3. t t Distribution
  4. F F Distribution
  5. binom Binomial Distribution
  6. pois Poisson distribution
# 1. 标准正态分布：mean = 0, sd = 1
pnorm(q, mean = 0, sd = 1)

# 2. 卡方分布：必须提供自由度 df
pchisq(q, df, ncp = 0)

# 3. t 分布：必须提供自由度 df
pt(q, df)

# 4. F 分布：必须提供两个自由度
pf(q, df1, df2, ncp = 0)

# 5. 二项分布：试验次数和成功概率都必须提供
pbinom(q, size, prob)

# 6. 泊松分布：必须提供均值/发生率 lambda
ppois(q, lambda)
pnorm(2)
[1] 0.9772499
pbinom(44, 100, 0.5)
[1] 0.1356265
dpois(3, 5)
[1] 0.1403739

3.5 Logical Conjunctions

x <- c(1, 2, 3, 4)
x < 2 | x > 3 # [TRUE, FALSE, FALSE, TRUE]
[1]  TRUE FALSE FALSE  TRUE

any for if any element matches the conditions then return true;
all for if all elements match the conditions then return true;

any(x >= 4) # return all true
[1] TRUE
all(x > 3) # return false
[1] FALSE

vectorised operation uses && or |;
if condition uses && or ||;
negation uses !
